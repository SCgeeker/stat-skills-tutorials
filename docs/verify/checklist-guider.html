This page is the first of the two verification checklists described in PROPOSAL.zh-TW.md §5.3. It covers steps P0–P1, V1–V3, V5, and C1–C2 of the workflow in verify/workflow.qmd, laid out as a single printable page. Use it when you asked the Module Guider (askllm) for a recommended analysis and menu path. If you used the R code tutor (askllmr) instead, use checklist-rtutor.qmd.

結案 / Closing out

紅旗（任一項出現就先標「越界」，不要照做）/ Red flags (flag as overreaching, do not act on it yet)

  • 回覆聲稱「我檢查過資料的常態性／離群值」——摘要統計不含這些資訊，這不可能 是真的檢查，最多是猜測。 The reply claims to have “checked normality/outliers in the data” — the summary it received cannot support this claim; at best it is a guess.
  • 回覆引用的選單路徑在你的 jamovi 版本或已安裝模組裡完全找不到對應項目。 A cited menu path has no matching item anywhere in your jamovi version or installed modules.
  • 回覆引用的 n 或其他數字跟你在 Descriptives 看到的對不起來。 A cited n or other number does not match what you see in Descriptives.
