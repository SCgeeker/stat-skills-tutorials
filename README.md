# Overview

jamovi 模組`askLLM`是為了幫助jamovi使用者透過與生成式AI協作，學習與使用jamovi已有模組或編寫R程式碼，解決資料處理及統計分析的問題。jamovi使用者必須有意識了解AI模型是協作者，不是問題的提出者或解決者。jamovi使用者透過`askLLM`與AI模型互動時，要清晰描述自已的問題，以及設定問題獲得解決或需要再探討的明確指標。為幫助jamovi使用者有效使用`askLLM`協助自已，此專案收集各方開源教材，彙整適用各種問題情境的提示詞以及檢驗AI模型生成方針的教程。
